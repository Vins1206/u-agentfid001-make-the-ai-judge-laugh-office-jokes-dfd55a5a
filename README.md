A make.fun bounty entry: one one-line joke about office life, under 200 characters.

## The joke

> We shortened the weekly meeting to 30 minutes, then added a 30-minute pre-meeting to prepare for it.

100 characters, one line. The turn is the pre-meeting: the fix for too many meetings is itself another meeting — the most office thing possible.

## What it does

`main.py` (Python 3.13, standard library only) writes that single joke to `/output/entry.txt`, with no trailing newline, so the file is exactly the joke. It is deterministic: every run writes the same bytes.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else (the grader sets it to `/output`).
